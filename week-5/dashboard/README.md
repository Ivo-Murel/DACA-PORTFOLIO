Grupitöö:

- Sai loodud 2 diagrammi sobivate tüüpidega oma stakeholder'ile

Individuaalne töö:
1. Installeerisin PowerBi ja ühendasin Supabasega
2. Laadisin ülesse andmebaasi tabelid
3. Genereerisin esimesed joon, tulp ja sektordiagrammid
4. Lisasin slicerid, muutsin pealkirju ning lisasin ka väärtused tulpdiagrammi peale
5. Laadisin .pbix faili githubi
